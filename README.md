# Central Comercial

Funil comercial da equipe: leads e Super MQL, sessões, relatório diário, metas, custo por etapa e aprovações do gerente.

A página é estática. Os dados ficam no Supabase, protegidos por login: só quem está na equipe vê alguma coisa. A chave que aparece no código é a chave pública (publishable) do Supabase.
